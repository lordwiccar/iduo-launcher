# iDuo Launcher 1.1.9

iDuo Launcher 1.1.9 (version code 12) follows feedback from users of Samsung foldables: apps cloned with Dual Messenger, and Liquid glass that keeps bending the wallpaper.

## Highlights

- **Dual Messenger**: apps cloned with Samsung's Dual Messenger (Android's clone profile) now appear in **All apps** and search, right after their originals and marked with Android's badge. Put them on Home, in the dock or in folders like any other app. Uninstalling a clone from iDuo removes only the clone.

## Fixes

- Samsung foldables keep a separate wallpaper for each screen. Folding or unfolding the phone made iDuo think its wallpaper had been replaced, so it stopped drawing it: Liquid glass no longer bent the wallpaper, and Home could lose the photo's chosen position. iDuo now keeps its wallpaper while either screen still shows it. A wallpaper that was already lost needs to be set again in iDuo once.

## Install

Install from Google Play, or download `iDuoLauncher-1.1.9-release.apk` from this release. It updates 1.1.8 installed from the same source; the Play version and the GitHub APK are signed differently and do not update each other.

## Privacy

Nothing changes: no account, ads, analytics or tracking. See the [privacy policy](../privacy-policy.md).

## Known limits

- Tested on a Galaxy Z Fold 7 and on emulators, but not on a Fold 8 itself.
- Android tells launchers which profile holds clones only from Android 15. On earlier versions cloned apps may appear under **Work** instead.
- After a wallpaper is set in iDuo, changing only the other screen's wallpaper in Samsung's settings leaves iDuo's wallpaper on both screens; set the wallpaper in iDuo or in Samsung's settings for both.
- The new "Clone" label was translated with machine help and has not yet been reviewed by native speakers. Corrections are welcome.
