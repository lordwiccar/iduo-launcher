# iDuo Launcher 1.1.7

iDuo Launcher 1.1.7 (version code 10) turns the left page into an extra Home page if you want one, adds a Liquid glass style and three languages, redraws the status ring, and addresses Home getting stuck when a Galaxy Z Fold 8 opens.

## Highlights

- **Extra Home page**: **Settings → Left page** now offers an **Extra Home page** beside Google News and your RSS feeds. Swipe right from the first Home page, or drag an app across the edge, and use it for apps, folders and widgets like any other page, on both screens. What it holds stays saved while the left page shows news, and is included in layout backups.
- **Liquid glass**: **Settings → Wallpaper & appearance → Glass style** makes the dock, folders, news and All apps clear glass with bright edges. The dock and large folders bend a wallpaper set in iDuo at their edges, and the bent picture blurs along with the wallpaper around it.
- **Languages**: Simplified Chinese, Japanese and Korean join English, Czech, Slovak, Polish and German.
- **Status ring**: a slimmer ring, a narrower opening with square ends for the battery level and a new Wi-Fi symbol. Without Wi-Fi it shows four signal bars with the network, such as 5G, in the bottom opening. The second SIM's unlit dots are easier to see.
- **Dock background**: **Settings → Dock → Dock background** turns off the glass, so custom icons can float on the wallpaper.

## Fixes

- Galaxy Z Fold 8: opening the phone could leave Home stuck in a narrow strip in the middle of the inner screen. Home now tells the screens apart by the display itself, and restarts its window if it stays that narrow. This was reproduced on an emulator at the Fold 8's sizes, not yet confirmed on the phone itself, so please report it if you still see it.
- The folding animation no longer stays blurred while the phone is left half open.

## Install

Install from Google Play, or download `iDuoLauncher-1.1.7-release.apk` from this release. It updates 1.1.6 installed from the same source; the Play version and the GitHub APK are signed differently and do not update each other.

## Privacy

Nothing changes: no account, ads, analytics or tracking. See the [privacy policy](../privacy-policy.md).

## Known limits

- Android does not let apps read a wallpaper set elsewhere, so over one the Liquid glass stays clear and does not bend it. Choosing the same picture under **Your photo** gives the full effect, and Glass style offers this.
- The new languages were translated with machine help and have not yet been reviewed by native speakers. Corrections are welcome.
