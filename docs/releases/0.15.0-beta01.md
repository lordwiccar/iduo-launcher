# Duo Launcher 0.15.0-beta01

An experimental Android launcher for foldables, with a right-side dock, native widgets and overlapping Home pages when unfolded. Android 12 or later is required; the tested configurations below are narrower than that minimum.

## Download and install

Use **DuoLauncher-0.15.0-beta01-release.apk** from the release assets (about 2.7 MiB). Open it on the phone, allow installation from that source if Android asks, and open Duo Launcher. The welcome screen lets you try Home, choose it as your default, or add a widget. All optional access can be skipped.

To switch back, use Android **Settings → Apps → Default apps → Home app**. Vendor labels may vary. [The user guide](../user-guide.md) covers the everyday controls.

Updates signed with the same release key can install over this beta. A developer/debug build may use a different key and cannot be updated directly with this APK. Keep that configured installation intact rather than uninstalling to bypass a signature error; see [update troubleshooting](../troubleshooting.md). Uninstalling removes saved launcher data and widget bindings.

The assets also include **DuoLauncher-0.15.0-beta01-source.tar.gz** and **SHA256SUMS.txt**. The APK's SHA-256 is:

## Included in this beta

- A persistent right-side dock, Home status rail, alphabetical All apps and Google search with local app-search fallback.
- Fold-aware Home pairs and an editable workspace visible only when unfolded.
- Native Android widgets with previews, resizing, scrolling and dragging between pages.
- App dragging, pages created during edge dragging, folders, and separate personal/work catalogs where Android policy allows them.
- Local photo backgrounds, light/dark/system or sunrise/sunset appearance, and layout export/import.
- Fresh-install setup, long-press Help, clearer Wi-Fi strength levels, and recovery choices when Discover is unavailable.

Wallpaper selection stages a preview before applying it. If selection is interrupted, Duo can recover a prepared preview or preserve the current background when recovery fails. This feature does not restore deleted photos.

## Tested scope and limits

The reference Galaxy Fold8 on Android 17 passed an in-place developer-signed update, actual live Discover and Home return, with all 12 widget bindings and saved launcher settings preserved. Its existing signing identity was retained.

The public signed release separately passed a populated upgrade, native Clock binding/configuration recovery, cold start, reboot, large-text setup and Home selection on a disposable Android 15 emulator. Its bundled Google app could not supply a feed; Discover recovery and local search with Google disabled worked. This does not establish live Discover support on every Android 15 device.

The build passed 136 JVM tests, 44 focused cover/inner interaction tests, and lint with no errors. Longer release performance/battery testing, another physical Fold/vendor configuration and real cellular signal testing remain open. The reference Fold has no SIM.

Discover depends on Google and device embedding support, including a version-scoped compatibility workaround. Work widgets depend on administrator policy. Private Space, icon packs, notification dots and nested/dock folders are not supported. Secure lock-screen replacement and hinge-driven cross-display animation are outside this beta.

## Privacy and feedback

Duo has no account service, analytics or automatic crash upload. Widget binding, shade gestures and approximate location are explained at their points of use; Google features use the Google app's own services. Read the [privacy notes](../../PRIVACY.md).

Report problems through the repository's bug form with app/Android version, device model, folded/unfolded state and steps to reproduce. Mention the provider for widget problems. Review screenshots and logs for personal/work data before sharing them.
